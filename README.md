# درس‌های ترم · پاییز ۱۴۰۵

یادداشت‌های درسی تعاملی (فارسی، راست‌به‌چپ) برای درس‌های این ترم. هر درس به ۲۰ جلسه تقسیم شده است.

- [`mlsd/`](mlsd/) — طراحی سیستم‌های یادگیری ماشین (جلسه‌های ۱ تا ۱۱ · [مرور میان‌ترم ۲ آذر](mlsd/review.html))
- [`dynamics/`](dynamics/) — آشنایی با سیستم‌های دینامیکی (جلسه‌های ۱ تا ۱۵)
- [`sim/`](sim/) — شبیه‌سازی کامپیوتری (جلسه‌های ۱ تا ۱۳)
- [`da/`](da/) — تحلیل داده‌ها (جلسه‌های ۱ تا ۱۲ · [مرور میان‌ترم ۱۰ آذر](da/review.html))
- [`ent/`](ent/) — مبانی کارآفرینی (جلسه‌های ۱ و ۷ از ۱۲)

سایت با GitHub Pages از شاخه‌ی `main` منتشر می‌شود. صفحه‌ها کاملاً ایستا هستند (HTML + JS + KaTeX) و به سرور یا build نیاز ندارند.

محتوای جلسه‌ها خلاصه و توضیح خود من از مطالب درس است. اسلایدها، کتاب‌ها و فایل‌های اصلی درس در این مخزن قرار نگرفته‌اند.
